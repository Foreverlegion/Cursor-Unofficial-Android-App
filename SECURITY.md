# Security

If you believe you have found a security issue in the Cursor Unofficial Android app (`com.cursorandroid.app`), please report it **from inside the app** using Settings → Report a bug (coming in an upcoming update).

Do not open a public GitHub issue. This repository has no public issue tracker and does not accept security reports through GitHub Issues, Discussions, or pull requests.

Please include enough detail to reproduce the problem, and avoid posting secrets (API keys, tokens, or personal data) in the report text.
