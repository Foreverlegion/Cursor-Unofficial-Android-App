# Cursor Unofficial Android

Unofficial Android client for **Cursor Cloud Agents**.

This project is **not affiliated with, endorsed by, or sponsored by Anysphere or Cursor**. It is a personal, unofficial app by Foreverlegion (Play developer account: Vexide). Package name: `com.cursorandroid.app`.

## Install

Installs are **only through Google Play** (Closed Alpha / testing track). There are **no APK or AAB downloads** from this repository, and no GitHub Releases with binaries.

Play Store listing (placeholder until the listing URL is final):

https://play.google.com/store/apps/details?id=com.cursorandroid.app

## Bug reports and feedback

There is **no public issue tracker** on this repository. Do not open issues here.

Bug reports and feedback are sent **from inside the app** (**Settings → Report a bug**). Each submission is an anonymous report with the text you write plus the app version and Android version. No name, email, API key, or device identifier is attached.

For policy questions, see [PRIVACY.md](PRIVACY.md) (contact: foreverlegion@gmail.com).

## What this repo is

This repository is the **public home** for the Play Store app: README, privacy policy, and security contact notes only.

Source code and builds live elsewhere and are private. This repo does not publish workflows, releases, or binaries.
